# AI Engineering Projects

A collection of hands-on projects built while developing practical
AI Engineering and LLM application skills.

## Projects

### 01. WebBrief AI
An AI-powered web application that extracts website content and
generates a concise summary using an LLM.

**Tech:** Python, LLM API, BeautifulSoup, Gradio

### 02. ModelArena AI
A simple LLM comparison application that sends the same prompt
to multiple models/providers and presents their responses for comparison.

**Tech:** Python, OpenAI-compatible APIs, Groq, Gradio
